# SOC Analyst Project: Network Traffic Analysis Using Wireshark

## Project Overview

This project focuses on network traffic analysis using **Wireshark**, a network protocol analyzer widely used in Security Operations Centers (SOCs) to monitor, inspect, and investigate network communications.

The objective was to analyze captured network traffic (PCAP files), identify suspicious activities, understand communication patterns, and investigate potential security threats.

## Tools Used

- Wireshark
- PCAP network traffic files
- Display filters and packet analysis techniques

## Practical Activities Performed

### 1. Identifying IP Addresses
- Analyzed network packets to identify source and destination IP addresses.
- Examined communication between devices on the network.
- Used IP information to understand network traffic patterns.

### 2. Brute Force Attack Detection
- Investigated network traffic for signs of brute-force attempts.
- Identified repeated authentication requests.
- Examined suspicious login activity that could indicate unauthorized access attempts.

### 3. Cleartext Password Identification
- Analyzed unencrypted network traffic.
- Identified credentials transmitted in cleartext.
- Learned how insecure protocols can expose sensitive information.

### 4. Following TCP Streams
- Used the Follow TCP Stream feature to reconstruct conversations between communicating devices.
- Examined the data exchanged between clients and servers.
- Gained insight into how network communication can be investigated during incident response.

### 5. Hidden Data Analysis
- Investigated packet contents for hidden or unusual data.
- Examined packet payloads to identify information that may not be immediately visible in normal traffic summaries.

### 6. VoIP Call Analysis
- Examined Voice over Internet Protocol (VoIP) traffic.
- Identified VoIP-related network communication.
- Explored how Wireshark can be used to analyze voice traffic and investigate communication patterns.

## Skills Developed

Through this practical exercise, I gained hands-on experience using Wireshark to investigate network traffic and identify potential security issues.

I learned how SOC analysts use packet analysis to investigate suspicious network activity, recognize insecure communication, and gather evidence that can support security incident investigations.
